# המסע שלנו · Trip Wallet

A trip expense tracker that runs entirely on the phone: no server, no account, works offline.
Data is stored only on the device; use "גיבוי לקובץ" (backup) and "שחזור מגיבוי" (restore) to move or protect it.

On iPhone: open the site in Safari → Share → Add to Home Screen, then open it from the home screen icon.

This repository holds the built site only. It is generated from the private source repository with `npm run build:static`.
